📔 Diário do Estudante 🗒


O que é o Diário de Estudos?

O Diário de Estudos é uma caderneta usada pelo Estudante para registrar o que se estudou num certo dia, o que você pretende estudar no dia seguinte ou, até mesmo, anotar curiosidades e fazer resumos. Serve, principalmente para organizar a vida acadêmica e praticar o HTML + CSS cotidianamente com mais leveza.

Funcionamento

  • O Index Págs serão as páginas das disciplinas feitas pelo google docs, utilizada para revisar conteúdos mesmo sem um caderno.

  • O Calendário, será a caderneta do que foi estudado num certo dia.
    Fórmula:
    Data Completa -> Dia da Semana -> Disciplina -> Assunto
